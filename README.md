# openads-lizmap-api
Connecteur PHP entre openADS (logiciel d'instruction des autorisations d'urbanisme) et l'API Lizmap (SIG WebGIS). Permet de vérifier des parcelles cadastrales, calculer emprises et centroïdes, récupérer des contraintes d'urbanisme, et générer des URLs de redirection cartographique, via cURL avec authentification HTTP basique.
